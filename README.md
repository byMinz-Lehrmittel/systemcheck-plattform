# Systemcheck – Online-Plattform

Online-Plattform zum Lehrmittel «Systemcheck – wie Menschen ticken.» von byMinz.

## Aufbau

| Datei | Inhalt |
|---|---|
| `index.html` | Startseite mit Code-Eingabe |
| `uebersicht.html` | Inhalte für Lehrpersonen und Lernende |
| `audio-persoenlichkeiten.html` | Die vier DISG-Audios |
| `spiel-disg.html` | Spiel «Wer steckt hinter dem Buchstaben?» |
| `spiel-energie.html` | Spiel «Energie regulieren in der Schule» (folgt) |
| `media/audio/`, `media/video/` | Audio- und Videodateien |
| `assets/img/` | Bilder aus dem Layout |
| `css/style.css` | Gestaltung |
| `js/main.js` | Code-Prüfung, Audio-Player, Video-Fenster |
| `js/spiel-disg.js` | Spiel-Logik und Texte des DISG-Spiels |

Der Zugangscode steht in `js/main.js` (Zeile mit `code:`).
